# 02. Glosario

Vocabulario común para requisitos, reglas y casos de uso. Cuando un término tiene un nombre fijo en la interfaz, se indica entre comillas.

| Término | Definición |
|---|---|
| **Incidente crítico** | Situación imprevista de aula que interrumpe la planificación pedagógica y que el estudiante analiza en sus talleres. |
| **Relato** | Texto con que el estudiante describe y analiza un incidente crítico. Se compone de cuatro secciones: Contexto, Descripción del hecho, Actores e influencia y Relevancia pedagógica. |
| **Taller** | Actividad reflexiva semanal con Objetivo, Actividad y Producto esperado. Hay cuatro, de desbloqueo lineal. |
| **Taller 1** | Identificación del incidente crítico. |
| **Taller 2** | Del aula a la transformación profesional (deconstrucción analítica). |
| **Taller 3** | Confrontación teórica. |
| **Taller 4** | Transformación de la práctica e innovación pedagógica. |
| **Método R5** | Metodología de reflexión de Ángeles Domingo que sustenta los talleres. Su correspondencia detallada con los pasos del asistente está pendiente (PEND-09). |
| **Marco teórico** | Lista de referencias bibliográficas (formato APA, con DOI) que el estudiante debe estudiar antes de rendir el cuestionario diagnóstico. |
| **Evaluación diagnóstica** | Cuestionario de 10 preguntas aleatorias de un banco de 30, con temporizador. Se aprueba con 8 aciertos. |
| **"El Impulso"** | Panel de la IA que entrega orientaciones para profundizar la reflexión. Nunca redacta ni corrige el texto del estudiante. |
| **Impulso / orientación** | Observación breve de la IA sobre un criterio omitido en el relato. |
| **Intento de revisión** | Cada solicitud de impulso a la IA sobre un taller. Descuenta del contador del taller. |
| **Borrador** | Versión guardada de un relato sin pedir revisión. Guardarlo no descuenta intentos. |
| **Rúbrica / matriz del taller** | Criterios con que la IA y el profesor evalúan un relato. |
| **Whitelist** | Lista de correos institucionales autorizados a ingresar, con estado y rol. |
| **Revocar acceso** | Quitar el acceso a un usuario de forma reversible. |
| **Eliminar usuario** | Borrado definitivo de la whitelist, con doble confirmación (para estudiantes que se retiran de la asignatura). |
| **Anonimización** | Reemplazo de nombres reales de personas, colegios o lugares por etiquetas genéricas ("Estudiante A", "Colegio X"). |
| **Filtro de confidencialidad** | Detección de datos sensibles que bloquea el envío del relato hasta que se anonimice. |
| **Panel de progreso** | Vista del estudiante con su avance en el marco teórico y los talleres, coloreada según el desempeño (ver "Colores de desempeño"). |
| **Panel docente** | Vista de seguimiento semanal del avance de los estudiantes. |
| **Validar (reflexión)** | Acción del profesor que confirma o edita los impulsos y registra la nota oficial. |
| **Nota oficial** | Calificación de 1,0 a 7,0 asignada por el profesor guía y guardada en Firestore. Es la que prevalece. |
| **Nota máxima por bloque** | Tope de nota del cuestionario según el número de intento: 1 a 3 → 7,0; 4 a 6 → 5,0; 7 a 9 → 4,0. |
| **Repositorio de innovaciones** | Biblioteca de propuestas finales con nota ≥ 6,0, anonimizadas, para consulta de estudiantes y profesores. |
| **Profesor guía** | Docente responsable de la asignatura de práctica profesional. |
| **Administrador** | Coordinador que gestiona la whitelist. Puede ser el mismo profesor guía. |
| **Colores de desempeño** | Gris: no entregado (1,0). Rojo: reprobado (< 4,0). Azul: aprobado (4,0 a 4,9). Verde esmeralda: sobresaliente (5,0 a 7,0). El rojo se usa solo con este sentido. |
| **UID** | Identificador de Firebase con que se particiona el almacenamiento local de cada usuario. |
| **HU** | Historia de usuario. |
| **RF / RNF / RN** | Requisito funcional / no funcional / regla de negocio. |
